# Rampant Arsenal (Fork)

## ⚠️ Fork Notice

This is a **community fork** of the abandoned [Rampant Arsenal](https://mods.factorio.com/mod/RampantArsenal/) mod, originally created by **Arch666Angel**.

**This is NOT the original mod.** This fork was created to maintain compatibility with Factorio 2.0 and add new features. For the original mod and its full history, visit the [official Factorio Mod Portal](https://mods.factorio.com/mod/RampantArsenal/).

## Changes in This Fork

### Factorio 2.0 Port
- Full compatibility update for Factorio 2.0
- Updated all prototypes and dependencies
- Maintained original gameplay balance and features

### New Features: Light Artillery Shells

Added lightweight variants of all Rampant Arsenal artillery shells with optional integration to the **snip-light-artillery** mod:

#### Light Shell Specifications
- **Damage:** 30% of original (70% weaker than standard shells)
- **Cost:** 70% of original recipe cost (30% cheaper)
- **Area of Effect:** Same as original shells
- **Unlock:** 
  - If **snip-light-artillery** is installed: Unlocks with Light Artillery technology
  - If **snip-light-artillery** is not installed: Unlocks with vanilla Artillery technology

#### Available Light Shells
1. **Light Incendiary Artillery Shell**
   - 180 fire damage (from 600)
   - Recipe: 1 steel plate + 1 explosives + 200 napalm fluid
   - Craft time: 5 seconds

2. **Light HE (High-Explosive) Artillery Shell**
   - 150 physical + 975 explosive damage (from 500 + 3250)
   - Recipe: 1 steel plate + 1 explosives + 1 cluster grenade
   - Craft time: 5 seconds

3. **Light Bio Artillery Shell**
   - 120 poison damage (from 400)
   - Recipe: 1 steel plate + 1 explosives + 3 toxic capsules
   - Craft time: 5 seconds

## Installation

Download from the [Factorio Mod Portal](https://mods.factorio.com/mod/RampantArsenalFork/) and enable in your mod list.

### Dependencies
- Factorio 2.0+
- **base** (required)
- **space-age** (optional) - Adds asteroid poison resistance
- **mech-armor** (optional) - Equipment compatibility
- **snip-light-artillery** (optional) - Light artillery tech integration
